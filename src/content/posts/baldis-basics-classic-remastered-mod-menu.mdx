### Information

This is a mod for the game "Baldi's Basics - Classic Remastered".

Want to walk through walls? Fly around? Mess with characters? Try some challenges that wouldn't be possible in the game normally?

The Mod Menu got you covered.

### Requirements

You'll need the original game for this mod. [Get it here (store.steampowered.com)](https://store.steampowered.com/app/1712830/) or [here (basically-games.itch.io)](https://basically-games.itch.io/baldis-basics-classic-remastered)  
You'll also need BepInEx 5 (BepInEx 6 will not work with this mod). [Get it here (github.com)](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.21)

### Features

* Make characters ignore you
* Change the speed, size and visiblity of characters
* Enable, disable and clone characters
* Edit your inventory and item values
* Character, notebook and Exit teleporters
* Infinite items
* Scene manager
* Noclip
* An answer to the impossible question
And more!
