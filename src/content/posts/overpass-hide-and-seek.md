> [!IMPORTANT]
> This map does not work while running the game in Counter-Strike 2 mode.  
> To play the map, you need to run in CS:GO mode, by enabling it through Steam Beta.

### Information

This is an edit of the map de_overpass by Valve, we did not make the original map.  
I'm only a Co-Developer for this map. gBGyo edited most of the map.

Max Players:  
16 T - 16 CT

Timings:  
T - 1 Minute to hide  
CT - 7 Minutes to seek

An edit of de_overpass with more props, less invisible walls, access to some roofs and added secrets (hidden doors and breakable walls).

### Requirements

You’ll need to own the game to use this map. [Get it here (store.steampowered.com)](https://store.steampowered.com/app/730/)
