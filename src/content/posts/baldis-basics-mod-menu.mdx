### Information

This is a mod for the game "Baldi's Basics in Education and Learning" and its subgames.

Want to walk through walls? Fly around? Mess with characters? Try some challenges that wouldn't be possible in the game normally?

The Mod Menu got you covered.

There are certain version differences.
* The unlocked camera does not work on Android by default, due to limitations of my workaround.
* The Field Trip Demo version is based on a very old Mod Menu version (v1.9.1).

### Requirements

You'll need the original game for this mod. [Get it here (basically-games.itch.io)](https://basically-games.itch.io/baldis-basics)

### Features

* Make characters ignore you
* Change the speed, size and visiblity of characters
* Enable, disable and clone characters
* Edit your inventory and item values
* Character, notebook and Exit teleporters
* Infinite items
* Scene manager
* Noclip
* An answer to the impossible question
And more!
